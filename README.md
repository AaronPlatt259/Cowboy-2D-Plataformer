## 2D platformer of a cowboy were you can change the environment and the enemies by pressing buttons. There are files for animations like the walking animations for the enemies and for the main character. Then we have the images for the winning and loosing screen, this two are just simple jpgs. Finally there are the png assets like the platforms, and the backgrounds.

## I considered making a level as simple as it can get, only one platform and one enemy so I don't end up messing it up with a lot of complexity.

## Definitivelly this was an interesting experience, I would want to learn more for next time and improve my learning flow for the things that I didn't know before starting the project. 

## Overall I loved this project and I felt pride when I saw the characters moving with such life, this was a very fun experience.
